# Pattern Practice

This repository contains C++ programs for practicing common console pattern problems.

## Folder Structure

```text
Patterns-Printing/
├── Hollow Diamond Pattern/
├── Square Pattern/
└── Triangle Pattern/
```

## Pattern Categories

- `Square Pattern` - square-based patterns such as star, letter, and number squares.
- `Triangle Pattern` - triangle patterns including inverted triangles, Floyd's triangle, and pyramid patterns.
- `Hollow Diamond Pattern` - hollow diamond and butterfly-style patterns.

## How to Compile and Run

Use `g++` from the `Patterns-Printing` directory.

```bash
g++ "Triangle Pattern/All_Triangle_Pattern.cpp" -o triangle
./triangle
```

```bash
g++ "Square Pattern/All_Square_Pattern.cpp" -o square
./square
```

```bash
g++ "Hollow Diamond Pattern/All_Hollow_Diamond_Pattern.cpp" -o hollow_diamond
./hollow_diamond
```

```bash
g++ "Hollow Diamond Pattern/ButterflyPattern.cpp" -o butterfly
./butterfly
```

## Notes

- Some files contain multiple pattern programs commented out.
- Uncomment only one `main()` function at a time before compiling.
- Folder names contain spaces, so wrap paths in quotes when compiling from the terminal.
